# О публичном справочнике

Ученическая версия для 9–11 классов находится в [оглавлении](notes/cpp-algorithms/README.md). Каждая тема занимает отдельную страницу Markdown, рассчитанную на чтение прямо на GitHub.

## Интерактивные примеры

Четыре модели из каталога `docs/` открываются на [GitHub Pages](https://yaroslav-yarik.github.io/cpm-robotics-programming/). Исходники находятся в `main`. Для публикации изменений в HTML или CSS обнови `gh-pages` обычной отправкой результата `git subtree split --prefix=docs HEAD`. Проверяй публичный адрес после сборки Pages. В главах ссылки находятся рядом с соответствующими схемами.

## Устройство компьютера и иллюстрации

Все 19 прежних тем связывают пример в коде с отдельной статической схемой. Четыре главы в `notes/cpp-algorithms/hardware/` объясняют логику, процессор, память и ввод-вывод. В оглавлении есть схема пути от клавиши до экрана. Обозначения и условные параметры каждой модели указаны на её странице. Файлы рисунков находятся в `notes/cpp-algorithms/assets/`. При изменении числового примера проверь значения в тексте, SVG и альтернативной подписи.

Источники для чтения приведены в соответствующих главах, в том числе архивные версии Berkeley CS61C, MIT xv6 и Algorithmica. Иллюстрации созданы для справочника.

## Редакция от 21 ноября 2026

Начальный раздел состоит из двух глав. В первой вводятся переменная, присваивание и копирование. Во второй массив связывает индексы, байты и адреса. Остальные главы используют разобранные примеры, таблицы состояний и схемы. В алгоритмических разделах C++17 виден сразу, а реализация на Python раскрывается рядом с ним. Два раздела по турам зарезервированы в конце оглавления.

При следующей вычитке удобно пройти от определения переменной к памяти и затем открыть одну алгоритмическую тему, например двоичный поиск. При редактировании нужно сверять промежуточные значения в схемах с кодом. В этой редакции проверены 74 локальные ссылки на Markdown и синтаксис кода в 25 парах реализаций.
