# О публичном справочнике

Ученическая версия для 9–11 классов открывается на [GitHub Pages](https://yaroslav-yarik.github.io/cpm-robotics-programming/). В каждой из 23 глав один опыт встроен между абзацами. В оглавлении четыре учебных раздела и два зарезервированных раздела по турам.

## Сборка интерактивных глав

Текст и иллюстрации редактируются в `notes/cpp-algorithms/`. Фрагмент опыта находится по тому же пути относительно `widgets/` и имеет расширение `.html`. Комментарий `<!-- interactive -->` в Markdown задаёт точное место его вставки. Оформление читательской версии лежит в `docs/style.css`.

Из каталога `tools/handbook/` выполни `npm ci` и `npm run build` (Node.js 18+). Скрипт преобразует Markdown в HTML, встраивает модели, копирует рисунки и обновляет `docs/`. Четыре прежних адреса перенаправляют к месту опыта в соответствующей главе. Для публикации сохрани обновлённые исходники и результат сборки в `main`; затем отправь результат `git subtree split --prefix=docs HEAD` в `gh-pages` обычным push. После сборки Pages проверь публичную версию.

При этой редакции проверены переходы, 88 исходных блоков кода, загрузка изображений, изменение модели в каждой из 23 глав и ширина 375 пикселей.

## Стиль примеров C++

В примерах подключай нужные заголовки и вынеси имена стандартной библиотеки в точечные объявления `using std::имя;`. Для переменных выбирай названия по смыслу, например `element_ptr`, `match_index` и `best_length`. Если переименовываешь переменную, сверь текст, схему и код, который показывает опыт.

## Устройство компьютера и иллюстрации

Все 19 прежних тем связывают пример в коде с отдельной статической схемой. Четыре главы в `notes/cpp-algorithms/hardware/` объясняют логику, процессор, память и ввод-вывод. В оглавлении есть схема пути от клавиши до экрана. Обозначения и условные параметры каждой модели указаны на её странице. Файлы рисунков находятся в `notes/cpp-algorithms/assets/`. При изменении числового примера проверь значения в тексте, SVG и альтернативной подписи.

Источники для чтения приведены в соответствующих главах, в том числе архивные версии Berkeley CS61C, MIT xv6 и Algorithmica. Иллюстрации созданы для справочника.

## Редакция от 21 ноября 2026

Начальный раздел состоит из двух глав. В первой вводятся переменная, присваивание и копирование. Во второй массив связывает индексы, байты и адреса. Остальные главы используют разобранные примеры, таблицы состояний и схемы. В алгоритмических разделах C++17 виден сразу, а реализация на Python раскрывается рядом с ним. Два раздела по турам зарезервированы в конце оглавления.

При следующей вычитке удобно пройти от определения переменной к памяти и затем открыть одну алгоритмическую тему, например двоичный поиск. При редактировании нужно сверять промежуточные значения в схемах с кодом. В этой редакции проверены 74 локальные ссылки на Markdown и синтаксис кода в 25 парах реализаций.
